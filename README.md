## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# writes out/entry.png — a 1024x1024 PNG, under 1 MiB, byte-identical on every run
```

No network, no dependencies beyond the Python 3.13 standard library. The image is original work drawn for this entry; it copies no other entrant's image, photograph or artwork.
